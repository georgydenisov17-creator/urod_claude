# Урод

2D-игра «Урод» — школьник на питбайке едет по русскому посёлку, перепрыгивает «Жигули», собирает бутылки «ГАЗЯВА» и катается на заднем колесе. Только статические файлы: без сборки, npm и внешних библиотек. Музыка играет из файла `music.mp3`.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **5 файлов**: `index.html`, `style.css`, `game.js`, `README.md`, `music.mp3` (Add file → Upload files).
3. Включите Pages: Settings → Pages → Source: Deploy from a branch → Branch: `main` → `/ (root)` → Save.
4. Откройте `https://ИМЯ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Как играть

- **ГАЗ** (слева внизу) — удерживайте, чтобы разгоняться. **ТОРМОЗ** — замедляет до полной остановки.
- **ПРЫЖОК** (справа внизу) — один прыжок за нажатие, в воздухе повторное нажатие игнорируется. Прыжок перелетает одну «Жигули».
- **ВИЛИ** — удерживайте, чтобы ехать на заднем колесе. За каждый метр даются бонусные очки. Индикатор угла краснеет к 80°, после 80° байкер падает.
- **Бутылки «ГАЗЯВА»** — +10 очков и одна бутылка в кошелёк. Часть бутылок висит в воздухе, их собирают в прыжке.
- **Магазин** — скины за бутылки: Неон (20), Камуфляж (40), Огонь (60), Космос (100). Покупки и выбранный скин сохраняются.
- **Процедурная генерация** — каждый забег создаёт новый уровень: бутылки, машины и посёлок на фоне. Между машинами всегда есть безопасная дистанция. Рекорд, бутылки и скины при рестарте сохраняются.
- Кнопка 🔊 в углу включает и выключает звук и музыку.
- Тап по экрану пропускает ролик падения.
- Максимальная скорость — 50 км/ч, игра ставится на паузу при переключении вкладки.

На ПК: ← тормоз, → газ, Space — прыжок, ↑ / W — вили.
